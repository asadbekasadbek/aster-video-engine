12 GiB assessment (engineering estimates, not measurements): f16 weights alone cost 2 bytes/parameter; 2B is about 3.73 GiB and 13B about 24.21 GiB before text encoder, VAE, activations and workspaces. Naive attention storage grows quadratically in token count; video increases tokens across time and space. Need chunking/offload/tiling and verified efficient attention. Adam-style full training additionally retains gradients and optimizer state, so weight fit does not imply training fit. RTX support and acceptable speed remain runtime questions. No training-quality claim.

## 2026-09-20 — M3.1/M4.1 implementation evidence
- [SafeTensors 0.8.0 API](https://docs.rs/safetensors/0.8.0/safetensors/tensor/struct.SafeTensors.html), Apache-2.0, inspected actual registry tensor.rs and Cargo.toml after user-authorized installation. `read_metadata` expects the whole file buffer; instead deserialize `Metadata` from bounded JSON via serde_json (already transitive) and validate file length separately. Registry `Metadata::new` checks offsets, dtype/shape size and overflow. Additional unique-name pass protects against HashMap overwrites. Tested Windows malformed/oversized/truncated/overlapping/duplicate fixtures, scalar/empty tensors and upstream parser agreement.
- [FFmpeg Y4M writer source](https://raw.githubusercontent.com/FFmpeg/FFmpeg/master/libavformat/yuv4mpegenc.c), LGPL-2.1-or-later; inspected format behavior, did not copy implementation. Rust writer emits header + FRAME markers + planar YUV420. [ffprobe options](https://ffmpeg.org/ffprobe.html) checked for independent frame count/rate/duration inspection.
- Existing external validator: FFmpeg n6.0-32-gd4a7a6e7fa-20230804, GPL/version3 enabled, not redistributed or a Rust runtime dependency. Rust-produced Y4M decodes fully; ffprobe reports rawvideo 320x180, 24/1, 48 frames, duration 2.000000. Optional H.264 preview made by external FFmpeg has same metadata; one midpoint image visually inspected (white square on dark background).
- [Candle 0.11.0 API](https://docs.rs/candle-core/0.11.0/candle_core/) plus actual downloaded package source checked. Published Cargo.toml uses tokenizers 0.22/onig, unlike main's 0.23/fancy-regex. Cargo.lock is the authoritative local dependency record. CPU matmul and square/sum backward smoke test passes; local CUDA still untested. Dependency license declarations: docs/dependency-licenses.md. No bulk data/model download.
- SD1.5 and tokenizer metadata APIs queried read-only; pinned revision, file sizes and LFS SHA-256 recorded in docs/sd15-candidate-manifest.md. API metadata is not a local hash verification. Candidate weights about 1.99 GiB; consent/license and model adapter remain outstanding.

## 2026-09-22 — world architecture feasibility, documentation research
- LLM-grounded Video Diffusion, arXiv:2309.17444v3 (2024-05-04): https://arxiv.org/abs/2309.17444 . Primary abstract describes dynamic layouts guiding attention and requires compatible classifier guidance. Evidence for explicit layout conditioning, not tested Rust support or persistent-world reuse. Paper/code/weight reuse licenses not audited; no material copied or downloaded.
- Blended Latent Diffusion, arXiv:2206.02779v2 (2023-04-30): https://arxiv.org/abs/2206.02779 . Primary abstract describes masked local image edits and reconstruction limitations. Engineering conclusion: masked editing must be validated separately from computational savings and temporal consistency. Paper links Creative Commons license; implementation/weight licenses remain unaudited; no code adopted.
- Stable Video Diffusion, arXiv:2311.15127: https://arxiv.org/abs/2311.15127 . Temporal model components and training distinguish video from independent image inference. Model-license gate remains the earlier model-card review; paper is not permission to download weights.
- W1 is original Rust symbolic state using std, no new dependencies, model or dataset. Bounded snapshots and atomic transitions can be tested without proving that neural rendering understands the world. Reuse, offloading, quantization and quality gains remain hypotheses until paired measurements. Framework comparison and provisional model choices remain in the 2026-09-20 ledger.
