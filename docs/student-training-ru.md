# Обучение модуля обработки видео Aster на Windows x64

## Из репозитория

Для сборки нужны Git, Rust/Cargo версии проекта (1.98), средства сборки C++ для Windows и FFmpeg с libx264 в PATH. В корне клона выполните:

```console
cargo aster-train
```

Cargo при необходимости скачает зависимости по Cargo.lock. При обычном клонировании пакет `training/packs/student-v1.mkv` (27 181 764 байта) скачивается вместе с исходниками. Если его нет в рабочем дереве разреженного клона, команда читает пакет из Git текущей ревизии. Контрольная сумма проверяется до обучения. Набор содержит шесть видеопотоков без потерь: исходные кадры и целевые кадры для двух обучающих клипов и отдельного проверочного клипа.

Команда обучит одобренную конфигурацию на CPU, заново загрузит полученные веса и создаст preview.mp4, student.safetensors и metrics.txt в новой папке artifacts/student-training/run-... . Для применения к своему видео подставьте напечатанный путь к весам:

```console
cargo aster-apply "путь/к/student.safetensors" "мой ролик.mp4" "результат.mp4"
```

Демо обрабатывает первые 25 кадров после приведения к 24 кадрам/с, сохраняет пропорции в кадре 576×384 и экспортирует видео без звука. Нужен исходник длительностью минимум 25/24 секунды. Обучаются параметры модуля обработки изображения. Генерация из текста с LTX описана отдельно в integrations/ltx/README.md.

## Эксперимент с отслеживанием в локальном архиве

1. Распакуйте весь архив в папку, куда можно записывать файлы.
2. Дважды нажмите Train-Aster.exe. Окно закроется после завершения. Для просмотра сообщений об ошибках можно запустить .\Train-Aster.exe из терминала в этой папке.
3. Откройте новую папку run-... . Файл candidate.safetensors содержит экспериментальные веса, metrics.csv — ошибки на отдельном ролике. Ниже ошибка — ближе к соответствующему образцу. При каждом запуске используется одно и то же начальное состояние для воспроизводимости.

В data/student.safetensors лежит одобренный модуль. Обучение не заменяет его и не меняет настройки вашего генератора.
В набор включены два обучающих клипа и один проверочный в виде RGB-массивов с готовыми целевыми кадрами. Они получены из текстовых генераций LTX-Video, детализация целей получена с помощью Real-ESRGAN. Личные фотографии в архив не входят. Для этого упражнения не нужно скачивать модели, собирать Rust или настраивать видеокарту. Проверено локально на Windows 11 x64. Для обычной генерации видео нужен отдельный движок Aster и его веса.

Для эксперимента со своим подготовленным набором: Train-Aster.exe train DATA_DIR OUT_DIR (обе папки должны существовать). Имена и размеры RGB24 файлов должны совпадать с примером: train-a, train-b, holdout с расширением .rgb, а также соответствующие -target.rgb, по 25 кадров размером 576x384. В DATA_DIR также нужен исходный student.safetensors. Держите проверочное видео отдельно от обучающих. Этот пакет воспроизводит небольшой эксперимент, обучение полного генератора в него не входит.

Архитектура ученика и код обучения находятся в integrations/ltx/examples/teacher_pilot.rs проекта Aster. Описание цели Spatial SR: https://github.com/xinntao/Real-ESRGAN . Источник исходных генераций: https://huggingface.co/Lightricks/LTX-Video .
